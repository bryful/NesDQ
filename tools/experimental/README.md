# FF2・FF3音声分離実験（解析再開）

2026-10-26のユーザー指示により解析を再開。戦闘 → ダンジョン → フィールド → その他の順に進め、使用頻度の低い処理は変更を抑える。通常版は `app/core_bridge.c` の入力補正のみを使い、この接続コードはリンクしない。

`ff2_core_bridge.c` は調査内容を残すための退避。イベント音の記録再生に着手した段階で中断しており、完成版として利用しない。`nesdq_ff2_check` と `nesdq_ff2_probe` は明示的に指定した場合だけビルドする開発用ターゲットで、この退避コードへリンクする。

現行仕様は `docs/ff-input.md`、過去の調査は `docs/ff2.md`。

再開後の観測ツール `nesdq_ff_audio_probe` と調査範囲は `docs/ff-audio.md` を参照。

通常版には `app/ff_audio.inc` のBGM・主要SE接続を組み込んだ。ここにあるイベント記録再生は実験のままとし、通常版はリンクしない。通常版の検査は `nesdq_ff_audio_check`。
