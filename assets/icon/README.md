Generation prompt:
Use case: logo-brand. Create one polished original square app icon concept for NesDQ, a Windows and Android emulator focused on Japanese 8-bit fantasy role-playing games. Concept A: Adventure cartridge. A bold ivory and warm crimson retro game cartridge silhouette, with an elegant small golden sword emblem embedded on its front label, against a deep midnight navy full-bleed square background. Limited 8-bit-inspired color palette, precise large pixel-art forms with deliberate stepped edges, polished restrained professional app icon design, strong readable silhouette at 48 pixels, centered and filling 75% of canvas, generous safe margins for Android circle cropping. Front-facing flat design. No words, no letters, no captions, no phone mockup, no external border, no drop shadows outside the canvas. An original design; no existing game characters or franchise logos. Output only a single finished icon, 1024x1024 square.

Foreground edit prompt:
Remove ONLY the dark navy background to make it truly transparent. Preserve the cartridge silhouette, ivory/red/gold colors, sword emblem, stepped pixel contours and square canvas margins. No redrawing, recoloring, cropping, additions, cast shadows or navy fringe.
